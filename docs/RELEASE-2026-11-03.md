## Verified

69 backend tests and 7 frontend tests pass. TypeScript checking, production builds, dependency audit and GitHub CI pass. Both APIs and workers are live. The actual PostgreSQL setup passed migration, private-storage, restricted-table and durable-queue preflight.

The owner completed Google sign-in in staging and production. Sign-in requests only identity scopes. Browser traffic remains same-origin through Vercel; provider tokens remain server-side. Anonymous session/trip/checkout access returns 401; the legacy unsafe purchase route returns 410. Direct anonymous database and public document access fail closed.

Hosted staging checks covered round-trip and one-way search, actual segment details, comparison, route-only airline handoff labels, refresh persistence, preference saving, pasted confirmation review, trip persistence, local-time month/agenda calendar and calendar-file download. The overnight staging fixture exports 22:00 New York as 03:00 UTC the next day and arrival at 10:00 UTC. A new search completed after worker restart. Production JFK–LHR returned 1,753 Duffel test offers and 685 matching itineraries. The phone (390px) and tablet (768px) landing layouts have no horizontal overflow.

Legacy preferences and two incomplete bookings were migrated only to the owner account. Bookings are review drafts, with missing fields preserved for correction. The read-only source remains intact.

Live booking remains gated by provider approval and purchase/recovery validation. Provider-level custom monitoring and budget alert policies beyond the verified Supabase spend cap are not claimed as configured. Render deployment health and application quotas are active.

The second invited account’s interactive Google sign-in is pending: the owner chose to test it later. Automated account-isolation tests pass; they do not substitute for that interactive check. Accessibility semantics and keyboard controls were reviewed, but no full assistive-technology audit is claimed. Staging Free may pause and has different backup retention from Pro.

SHA-256 hashes are recorded beside the dumps. Keys remain in macOS Keychain and backend secret stores.

Private file bytes need separate object backup when documents are enabled; no documents were issued in this pilot.
